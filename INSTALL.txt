THELUCIFER-07 GitHub Profile README
===================================

README.md contains the profile artwork as GitHub-compatible ASCII text, so it
does not depend on a banner image or an external icon service. The editable
ASCII source artwork is stored in assets/ascii/.

To publish this profile, place these files in the repository whose name matches
the GitHub account, then commit and push them through your usual workflow.

Run the local layout checks with:

    python3 scripts/validate_readme.py

To also check the links over the network, run:

    python3 scripts/validate_readme.py --check-links
