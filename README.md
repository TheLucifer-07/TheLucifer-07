## Featured projects

### Relay

A community-focused peer-to-peer platform for discovering, exchanging, and reusing resources within local communities.

**Built with:** React · Vite · Tailwind CSS · Node.js · Express · MongoDB · Socket.IO

[Repository](https://github.com/TheLucifer-07/Relay) · [Live demo](https://relay-community-one.vercel.app)

### EduNexes

A student productivity platform that brings learning tools, AI workflows, and academic organization together in one place.

**Built with:** React · Node.js · Gemini

[Repository](https://github.com/TheLucifer-07/EduNexes)
