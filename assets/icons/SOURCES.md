# Technology icon sources

The Java cup and SQL database marks are original monochrome SVGs created for this profile. The remaining marks are local copies of corresponding Simple Icons SVGs at version 16.37.0, recolored to #f2f2f2 on black tiles so they remain visible across GitHub light and dark themes. The artwork script rasterizes these local SVG sources into the PNG icons embedded by the README.

Simple Icons source: [github.com/simple-icons/simple-icons](https://github.com/simple-icons/simple-icons).
